# Development roadmap

Each phase ends with a reviewable artifact and evidence. The Windows MVP is the first release gate. Scope later phases independently so that a delayed model or kernel probe cannot block collection.

**Single-PC variant.** [LOCAL_PROFILE.md](LOCAL_PROFILE.md) scopes the first release to one host with a local database and no central server. Phase 1 deliverables apply except enrollment, transport, PostgreSQL and the Compose deployment; Phase 2 keeps the same local model.

**Current work.** `crates/protocol` implements the normalized event model, admission validation and the Windows 4624/4625 XML parser. `crates/agent-core` implements the WAL SQLite spool (`fact` plus compressed `raw`), atomic bookmark advancement, persisted bookmarks, source generations, gap records with lower bounds and audited retention with daily rollups. `crates/windows-source` owns the Event Log pull subscription and channel health rules, and `apps/agent` wires them into the local collector loop. Synthetic fixtures and contract tests cover every layer. The next increment is the loopback query API and browser explorer; Windows service packaging, privilege verification and channel sizing still need a clean-VM test.

## Phase 4 experiment

Aggregate five-minute windows by endpoint and account or service role. Compute failed/success counts, distinct source count, hour/day cyclical features, process frequency and destination novelty when those sources exist. Distinguish unavailable telemetry from a measured zero. Keep event IDs, window bounds, parser version and coverage with each feature row. Avoid raw usernames, IP integers and machine IDs as numeric model inputs.

Begin with minimum sample support, a rolling median and median absolute deviation by peer group and time of week. Fit transforms and models on earlier windows, tune thresholds on a later validation period, then freeze and test on later dates and held-out endpoints. Use Isolation Forest as a multivariate comparator. Fit LOF in novelty mode and score unseen data, monitoring inference cost as reference data grows. Freeze the training snapshot, seed, feature and model versions. [scikit-learn outlier and novelty detection](https://scikit-learn.org/stable/modules/outlier_detection.html)

Measure precision and recall on labelled episodes, precision at the daily analyst budget, false alerts per host-day and detection delay. Report label coverage and uncertainty by cohort. Start with at most one anomaly alert per 20 host-days, suppress repeat windows and expire maintenance exclusions. Inspect high-scoring benign shifts, missing data, new hosts and drift in shadow mode. Show deviations as investigation leads. Confirmation requires evidence and analyst disposition.
